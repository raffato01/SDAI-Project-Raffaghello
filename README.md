The project implements the *Cleaning Robots* scenario and includes a brief comparison between **Jason** and **JadeScript**.

## How to run

### Jason

The Jason implementation can be started using the provided launcher script:

- on **Windows**, run the `.bat` file;
- on **Linux/macOS**, run the `.sh` file.

The script compiles `MarsEnv.java` and starts the multi-agent system defined in `mars.mas2j`.

A Java JDK 17 or later is required.

### JadeScript

The JadeScript implementation must be opened with **Eclipse IDE** with the **JadeScript plugin** installed.

Once the project is imported into Eclipse, the system can be started using the provided `MainLauncher.java`.

For the complete description of the implementation, the comparison, and the obtained results, refer to the project report.
